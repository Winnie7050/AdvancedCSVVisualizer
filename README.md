# Advanced CSV Data Visualization Platform

A specialized Windows 10 application for analyzing and visualizing time-series CSV datasets with interactive charts and optimal performance.

## Features

- Native Windows 10 standalone executable
- Multiple visualization types (line charts, bar charts, pie charts, diverging bar charts)
- Advanced time-series data processing
- High-performance data handling for large datasets
- Customizable visualization styling with dark theme

## Development

This application is built using WPF (.NET 6) with a clean, modular architecture following MVVM principles.
